# Игры для Яндекс Игр и VK Игр

Исходники браузерных игр (HTML5 + JavaScript, без движка). Каждая игра собирается в один `index.html` и архив для консоли Яндекс Игр.

## Игры

| Папка | Игра | Жанр | Статус |
|---|---|---|---|
| `games/bitva-geroev` | Битва героев | автобой-арена + мастерская | готова, ждёт модерации |
| `games/bloki-samocvety` | Блоки-самоцветы | блок-пазл, приключение 60 уровней | готова, ждёт модерации |
| `games/kotapulta` | Котапульта | физическая головоломка (Matter.js) | готова, ждёт модерации |
| `archive/podvorie` | Сказочное подворье | merge | отложена |
| `archive/zarechny-krai` | Заречный край | пошаговая стратегия | отложена |

`release/` — последние архивы для загрузки в консоль Яндекс Игр.
`shared/` — общий код (звуки ZzFX).

## Яндекс Игры

- SDK подключается динамически: `/sdk.js` → `YaGames.init()` → `LoadingAPI.ready()`.
- Облачные сохранения, реклама (полноэкранная между партиями, за награду), лидерборды:
  - Битва героев — `trophies`, Блоки — `score`, Котапульта — `stars`.
